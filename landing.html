3가지 핵심 기능

인테리어 현장 업무에 꼭 필요한 것만 담았습니다

기능 01

공정 대시보드

여러 현장을 카드 하나하나로 관리하세요. 공정 진행 상황, 외주 대금, 계산서·수금 현황까지 한눈에 파악할 수 있습니다.

  • 5단계 공정 상태 관리

    실측예정 → 실측 후 대기 → 시공확정 → 시공중 → 완료

  • 외주 관리

    외주 금액·날짜, 계산서 발행·대금 지급 여부를 현장 단위로 추적

  • 계산서·수금 현황

    미발급 합계 즉시 확인, 수금 상태(미수금/일부수금/완료) 관리

  • 캘린더 보기

    월별 캘린더로 공정·외주 일정을 현장별 색상으로 시각화

  • 엑셀 다운로드

    계산서 현황 리스트를 엑셀 파일로 즉시 내보내기

기능 02

견적서 작성

공급자 정보는 한 번만 입력하면 자동 저장됩니다. 고객 정보와 품목만 입력하면 전문 견적서가 완성됩니다.

  • 공급자 정보 자동 저장

    상호, 대표자, 사업자번호 등 로그인할 때마다 자동으로 불러옴

  • 일반 품목 + 옵션 품목 분리

    품명·단위·수량·단가·비고 입력, VAT 10% 합계 자동 계산

  • 로고 + 자사 소개 출력

    로고 업로드, 회사 소개 문구를 견적서 하단에 포함 여부 선택 가능

  • 클라우드 저장 + PDF 출력

    저장 내역에서 언제든 불러오기, 전문 양식으로 인쇄 또는 PDF 저장

기능 03

실측 템플릿

현장에서 바로 입력하는 디지털 실측 리포트입니다. 공간별 규격, 마감재 상태, 사진까지 체계적으로 기록하고 PDF로 출력하세요.

  • 공간별 규격 기록 (mm)

    가로(W)·세로(D)·천장고(H), 창문·출입문 위치/크기

  • 마감재 현황 + 교체 제안

    바닥재·벽면·천장의 현재 상태와 제안 자재를 나란히 기록

  • 공사 항목 체크리스트

    철거·바닥재·도배·목공·전기·배관·타일·조명·가구 등 10개 항목

  • 공간별 사진 첨부

    현장 사진을 공간마다 업로드, 실측 리포트 출력 시 함께 포함

실제 사용 흐름

현장 첫 방문부터 수금 완료까지

1

실측 기록

현장 방문 시 실측 템플릿으로 공간별 규격, 마감재, 사진을 현장에서 바로 입력합니다.

2

견적서 발송

실측 후 견적서를 작성해 PDF로 출력, 고객에게 바로 전달합니다. VAT 포함 합계가 자동 계산됩니다.

3

공정·수금 관리

계약 후 공정 대시보드에서 공정 진행 상태, 외주 대금, 계산서·수금 현황을 한눈에 추적합니다.

공통 기능

어디서든 안전하게

클라우드 저장

모든 데이터가 실시간으로 저장됩니다. PC·모바일 어디서든 동일하게 접속 가능합니다.

엑셀 출력

계산서 현황을 엑셀로 다운로드합니다. 미발급 합계를 즉시 확인하고 외부 보고에 활용하세요.

PDF 인쇄

견적서·실측 리포트를 전문 양식으로 인쇄하거나 PDF로 저장해 고객에게 바로 전달하세요.

계정 보안

이메일 기반 인증으로 내 데이터만 접근 가능합니다. 다른 사용자의 현장 정보는 볼 수 없습니다.

자주 묻는 질문

여러 현장을 동시에 관리할 수 있나요?
네. 공정 대시보드에서 현장을 무제한으로 추가할 수 있습니다. 각 현장은 카드 형태로 표시되며, 캘린더 보기로 전체 일정을 한눈에 볼 수 있습니다.
견적서는 몇 개까지 저장할 수 있나요?
견적서와 실측 리포트 모두 제한 없이 클라우드에 저장됩니다. 저장 내역 목록에서 고객명과 날짜로 빠르게 찾아 불러올 수 있습니다.
모바일에서도 사용할 수 있나요?
네. 별도 앱 설치 없이 스마트폰 브라우저에서 바로 사용할 수 있습니다. 현장에서 스마트폰으로 실측을 입력하고 사무실 PC에서 확인하세요.
공급자 정보를 매번 다시 입력해야 하나요?
아닙니다. 견적서 작성 화면에서 공급자 정보를 한 번 저장하면, 다음 로그인부터 자동으로 불러옵니다.
외주 업체 대금도 관리할 수 있나요?
네. 공정 대시보드에서 현장별로 외주 항목을 추가할 수 있습니다. 외주 금액, 날짜, 계산서 발행 여부, 대금 지급 여부를 체크박스로 간편하게 관리합니다.
